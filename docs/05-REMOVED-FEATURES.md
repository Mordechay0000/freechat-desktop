# יומן הסרות — דסקטופ

כל דבר שהוסר מהלקוח או הוחלף בו מתועד כאן, עם איך מחזירים. התבנית זהה ל-
`freechat-android/docs/05-REMOVED-FEATURES.md`. הקובץ הזה נוצר רק עכשיו (2026-10-07), למרות
שההוראה לתעד כל הסרה קיימת מההתחלה: **הסרות קודמות בדסקטופ לא נרשמו**, והרשומות למטה הן מה
שאפשר היה לשחזר מהקוד. מי שמוצא פער, שיוסיף.

### אייקונים, לוגואים וסמלי tray של מותגים אחרים
- **תאריך**: 2026-10-07
- **שכבה**: 3 (החלפת נכסים, שלב overlay מאוחר)
- **למה**: בביקורת נמצא שהדסקטופ נושא את מטוס הנייר של טלגרם (`Resources/art/*`, אייקון ה-About,
  ריבוע ה-QR), ואת הסימן של owpengram (`Resources/FreeChat/art/*`, כל אייקוני האפליקציה, ה-tray,
  ה-QR, אריחי UWP, ה-iconset של macOS). שינוי שמות לא נוגע בתמונות.
- **איך**: `python3 scripts/lib/gen_icons.py desktop .` מרנדר 136 קבצים משני ה-masters
  `desktop/branding/logo.svg` ו-`logo-glyph.svg` אל `desktop/overlay-late/`, באותם גדלי פיקסלים
  של upstream, כולל `.ico`. ה-overlay המאוחר מועתק **אחרי** ה-purge: ה-purge משנה את שם
  `Resources/<fork>/` ל-`Resources/FreeChat/`, ואייקונים שהועתקו קודם נדרסו שם (36 קבצים; נמצא
  בהשוואת העץ המוחל מול ה-overlay בייט-בייט). אנימציית המטוס במסך הפתיחה מורכבת מארבעה חלקים;
  לסמל החדש אין חלקים כאלה, לכן `intro_plane_top` נושא את כולו והשלושה האחרים שקופים.
  `telegram_logo_256.png` (כניסת "רשת אחרת" ברשימת השרתים) הוא עכשיו סמל ניטרלי, לא של מותג.
- **איך מחליפים לוגו**: לערוך את שני ה-SVG (viewBox `0 0 512 512`) ולהריץ את המחולל. הלוגו
  הנוכחי הוא placeholder. `selftest` נכשל אם ה-masters השתנו בלי הרצה מחדש.
- **מה נשבר בדרך**: כלום ידוע. אייקוני ה-send (גליף) לא הוחלפו; הם לא לוגו.
- **נבדק במכשיר**: לא. נבדק רק שהקבצים המוחלים זהים בייט-בייט למה שנוצר; **לא קומפל ולא הורץ**
  אחרי ההחלפה (macOS נבנה אצלך לפני כן).

### צומת ברירת המחדל ומפתח ה-RSA של הפורק
- **תאריך**: לפני 2026-10-07 (הוסיפו אותו ה-purge, שלא נרשם)
- **שכבה**: 3
- **למה**: הלקוח נשא את מפתח ה-RSA ואת כתובת ה-IP של הצומת של הפורק, כלומר היה יכול להתחבר
  אליה בשקט.
- **איך**: `purge_branding_desktop.py` מרוקן את `kOfficialRsaPublicKey` ואת
  `kOfficialDefaultHost`, ומנטרל ערכי שרת מובנים.
- **איך מחזירים**: `FREECHAT_INCLUDE_TELEGRAM=true` משאיר את הערכים המקוריים.
- **נבדק במכשיר**: נבנה ורץ ב-macOS אצלך; הקצה הזה לא נבדק בנפרד.
